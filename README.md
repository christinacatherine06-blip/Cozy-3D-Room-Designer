# Cozy 3D Room Designer
A WebGL2 + GLSL interactive bedroom design project (no Three.js).

## Run
Open this folder in VS Code, install the Live Server extension, right-click `index.html`, and choose **Open with Live Server**. Alternatively run `python3 -m http.server 8000` in the project folder and open http://localhost:8000.

## Current progress
Phase 2 starter: floor and two visible walls built with triangles and vertex buffers, custom GLSL shaders, and view/projection matrices. The remaining furniture, clock, lighting, camera controls, and interactions will be added in later phases.
